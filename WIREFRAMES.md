```
┌──────────────────────────────────────────────┐
│  👔 Wordrobe                        v0.0.1   │
├──────────────────────────────────────────────┤
│   글귀     페르소나     [ 변환 ]             │
├──────────────────────────────────────────────┤
│                                              │
│  대충 쓴 문장                                │
│  ┌────────────────────────────────────────┐  │
│  │ 오늘 회의 늦어서 미안                  │  │
│  │                                        │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  모델: [Flash ▾]    안 수: [3 ▾]             │
│                                              │
│                                [✨ 멋지게]   │
│                                              │
│  ─── 결과 ───────────────────────────────    │
│                                              │
│  ① "오늘은 흐름을 조금 늦췄습니다.           │
│      양해를 구합니다."        [복사] ★      │
│                                              │
│  ② "회의 시작을 늦춰 미안합니다.            │
│      이어가시죠."             [복사]         │
│                                              │
│  ③ ... (스트리밍)                            │
│                                              │
└──────────────────────────────────────────────┘
```

### 상호작용
- `✨ 멋지게` 클릭 → Gemini 스트리밍 시작 → 첫 토큰 도착 시 즉시 ① 박스에 흐름 표시.
- ★ 별표 = 사용자가 "이 안이 마음에 들었음" 신호 → 향후 페르소나 보정에 weighting (Phase 2).

## 결정된 UX 원칙 (참고)

1. 모든 화면에서 푸터에 "이 기기에만 저장" 문구 상시 노출.
2. 변환 결과는 항상 1~3안 카드. 단일 결과로 가두지 않음.
3. 페르소나는 항상 사람이 읽을 수 있는 마크다운으로 노출 — 블랙박스 금지.
